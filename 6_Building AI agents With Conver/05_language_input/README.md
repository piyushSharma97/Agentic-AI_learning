
# Lesson 5 — Pass extra input to a prompt

## Goal
Learn that a prompt can accept more than the user's message.

## Run
```bash
python 05_language_input/main.py
```

## What to notice
The prompt has a `{language}` placeholder. The dictionary passed to `.invoke()` provides its value.

## Try it
Change `"Hindi"` to `"English"`, `"Spanish"`, or another language you want to test.
